Supported KES O‑ring formats
  • Classification codes: 07000, 07002, 02890–02895
  • General pattern: CCCCC-M-DDDD
  • Where:
    • CCCCC = classification (e.g. 07000)
    • M = material code digit
    • DDDD… = dimension code (thickness grade + inner diameter)
  • Examples:
    • 07000-22034
    • 07002-52014
    • 02890-12018
Material codes (KES O‑rings)
  • 0 → NBR‑1A (Nitrile rubber)
  • 1 → NBR‑1B (Nitrile rubber)
  • 2 → FR‑1B (Fluororubber)
  • 3 → FR‑1A (Fluororubber)
  • 4 → NBR‑1D (Low‑temp nitrile)
  • 5 → NBR‑1E (Low‑temp nitrile)
  • 6 → SR‑1 (Silicone rubber)
Thickness grades (07000 / 02890‑02895)
  • 1 → 1.5 mm
  • 2 → 2.0–2.5 mm (depends on ID range)
  • 3 → 3.0 mm
  • 5 → 5.0 mm
  • 6 → 6.0 mm
  • 7 → 6.8–7.1 mm
How this prototype works:
It focuses only on KES O‑rings and uses the Komatsu KES tables to decode: classification, material, color dots, inner diameter, thickness grade, and approximate temperature/pressure usage. The same pattern can later be extended to other KES parts, chassis parts, and engine parts.
